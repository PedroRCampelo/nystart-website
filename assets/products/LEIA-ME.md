# Prints dos produtos

Coloque aqui as capturas de tela exibidas em "Produtos que construímos".

## Formato e tamanho

| | |
|---|---|
| **Formato** | **WebP** (preferencial) ou JPG |
| **Tamanho** | **1600 × 1000 px** (proporção 16:10) |
| **Peso** | até ~300 KB por arquivo |
| **Conteúdo** | só a tela do sistema, sem a barra do navegador (o site já desenha uma moldura) |

## Nomes dos arquivos

| Produto | Arquivo |
|---|---|
| Whallet | `whallet.webp` |
| Apolize | `apolize.webp` |
| Whallet Route | `whalletroute.webp` |
| Produto 4 | `produto4.webp` (renomeie junto com o `index.html` quando o produto tiver nome) |

Enquanto o arquivo não existir, o card mostra um fundo listrado no lugar do print.

## Como tirar um bom print

1. Abra o sistema no navegador com a janela em **1440 × 900** ou maior
   (no Chrome: F12, ícone de celular/tablet, "Responsive", digite 1440 × 900).
2. Use dados de demonstração, **nunca dados reais de clientes**.
3. Capture a tela (no Chrome: F12, Ctrl/Cmd + Shift + P, "Capture screenshot").
4. Recorte/redimensione para 1600 × 1000 px. Se a imagem for mais alta, o site
   mostra a parte de cima e corta o resto.
5. Converta para WebP em [squoosh.app](https://squoosh.app) (qualidade ~80).

Se preferir salvar em JPG ou PNG, troque a extensão na linha correspondente do
`index.html` (procure por `assets/products/`).
